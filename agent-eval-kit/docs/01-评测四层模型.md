# 评测四层模型

> 来源：我的知识树/笔记沉淀（结合 Anthropic evals、评测→训练闭环、Reward Model 八层等）。
> 用途：判断"一个评测相关的工作/岗位/项目处在哪一层"，以及自己应该往哪一层走。

## 四层

```text
L4 评测驱动训练闭环   ← 评测 → bad case 归因 → 数据策略 → 训练迭代（数据飞轮）
L3 评测数据生产       ← 评测集构建：难度分级、防污染、合成数据、ground truth 生产
L2 评测体系设计       ← 指标定义、rubric/判分规范、Judge 可靠性、统计验证
L1 评测执行           ← 跑 benchmark、记录指标（可被自动化替代，天花板低）
```

## 关键判断

- L1 越来越不值钱：自动化 + LLM Judge 普及后，"会跑基准"不是能力。
- L4 越来越值钱：评测正从"验证模型"变成"驱动训练"——Reward Model 就是评测的极端形态。
- 多数人只会 L1/L2，少数人懂 L3，L4 是交叉点。

## 对应我的实践

| 层 | 实践 |
|---|---|
| L1 执行 | 跑基准、记录指标（理解其局限，不当作核心能力） |
| L2 体系设计 | Price-Agent 9 阶段分层评测、LLM Judge 四维 + 幻觉检测 |
| L3 数据生产 | 字节 CoT 质检（级联分类 + 黑盒配比）、VLM 多视频数据生产 |
| L4 闭环 | 评测→bad case 归因→数据策略（进行中，见 eval-to-training-loop 笔记） |
