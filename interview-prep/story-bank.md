## 二、故事总览（30 秒版本）

### 1. 字节 · CoT 质检 Pipeline ⭐⭐⭐（核心故事）

> 我在字节独立设计了 CoT 数据的多层级联分类质量门控系统：5 层 Gate（格式 → 内容 → LLM 修复 → 标签纠错 → 分布校验），处理 5,497 条数据，输出 4,346 条合格（79.06%），交付算法团队纳入预训练 Eval Set。打通众包 → 质检 → 修复 → 交付全闭环。

### 2. 字节 · VLM 多视频理解数据生产 ⭐⭐⭐（核心故事·进行中）

> 我在字节负责 VLM 多视频理解数据的生产标准与采集合成自动化。拆解标准文档，梳理 L1 感知、L2 对比、L3 推理三层能力维度体系，定义 JSON 交付格式与"逐视频逐证据"CoT 结构，推进关键词爬取 → TOS 入库 → 去重 → 自动生成 prompt 与初版 CoT 的自动化管线。

### 3. 百度 · 一键百看投放 Agent ⭐⭐（Agent 产品故事）

> 我在百度主导了品牌广告投放 Agent 的全链路设计：统一资产模型、物料迁移 Agent（迁移成功率 92%）、语义匹配召回、任务编排框架。投放链路操作步骤减少 60%，单物料时效小时级 → 分钟级，人力成本降低 98%。

### 4. 第四范式 · 航空机务私有化 MaaS ⭐⭐（技术产品化故事）

> 我在第四范式负责航空机务私有化 MaaS 平台核心模块：LoRA 微调产品化（场景模板 + 专家评测）、多源文档 RAG（多路混合检索）、意图识别多智能体路由（5 类助手）、"自动化测试集 + 机务专家校验"双模评测。

### 5. Price-Agent · 商品对比智能助手 ⭐⭐（自驱 Agent 项目）

> 我独立设计了一个 AI 比价搜索 Agent。核心是四类意图路由架构 + 手机品类 17 字段数据模型 + 7 阶段分层评测体系（158+ 用例），评测结论驱动了归一化规则、语义权重（α=0.7）、追问上限等关键迭代。

### 6. Kaggle · 广告欺诈检测 ⭐（数据能力硬证据）

> 我在 Kaggle 处理 2 亿条点击数据，针对 1:33 极度不平衡问题，设计 IP 分桶分布式处理 + 四类统计特征，LightGBM + 网格搜索 + Early Stopping，验证集 AUC 0.96，欺诈召回率 93%。

### 7. 第四范式 · 评测缺失的教训（复盘视角，并入故事 4）

> 我在第四范式参与 ToB 垂类模型交付时亲眼见过反面教材：没有评测体系的微调 = 盲人摸象——没有 baseline、没有测试集、没有 badcase 分析，模型效果无法量化也无法迭代。这段经历让我理解了 Evals 的不可或缺性，直接塑造了我在字节主动做质量验证的方向。

## 五、跨项目通用模式（面试中反复出现的"内功"）

模式 1：人机分层评估（确定性 → 概率性 → 人类）

├── 第四范式：5 类机务助手路由

├── 百度：Badcase 分类 → 双周迭代

模式 4：数据质量前置（Garbage in, garbage out）
├── 字节：5 层 Gate 质检
├── Price-Agent：归一化别名体系
└── VLM 项目：打码、去重、可配对视频选材
