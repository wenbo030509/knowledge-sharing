# Agent Insights — 深度使用记录

> 目的：把日常 Agent 使用变成面试弹药。记录的不是「它告诉了我什么」，而是「它做了什么、哪里失败、我会怎么设计」。
>
> 使用模式：**驾驭式使用**——委托真实任务（不是咨询问答），然后记录观察。
> 目标：8 月底积累 30+ 条记录，面试时能讲出「Agent 失败模式 + 设计改进」的具体案例。
> 建立：2026-08-05

---

## 记录模板（每条 3 分钟）

```text
### #001 YYYY-MM-DD：<任务一句话>

**任务**：我委托它做什么？（描述目标、约束、验收标准——我设计了什么）
**观察**：
- 做对了什么？（精确到具体交互/输出）
- 做错了什么？（幻觉、理解偏差、操作失误）
- 失败原因分析（如果失败了）：是模型问题还是我的设计问题？
**判断**：如果我是 PM，下个版本改什么？（工具设计 / prompt / 权限 / 反馈机制）

**连接知识树**：<Harness / Tool Calling / Context Management ...>
```

---

## 观察维度清单（帮助快速定位记录点）

```text
维度 1：任务完成度 —— 最终结果满足需求吗？（正确/部分/失败）
维度 2：过程效率   —— 几次交互完成？有没有无意义绕路？
维度 3：指令跟随   —— 有没有做我没说的事？漏掉我的要求？
维度 4：错误恢复   —— 出错后能自己发现并修复吗？还是需要我介入？
维度 5：工具选择   —— 用的工具对不对？有没有更优的工具它没想到？
维度 6：约束感知   —— 我对它的隐性约束它理解了吗？（harness/提示层的边界）
```
