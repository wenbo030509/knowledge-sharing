## 一、今日主题：Agent Harness 八层解剖

**触发点**：讨论「什么是真正的使用」→ 引出 harness 概念 → 挂载知识树 → 八层解剖。

**核心产出**：`notebook/Agent Harness 解剖.md`（完整八层，每层覆盖至少两个视角）

**解剖后一句话沉淀**：
> 能力在模型层，行为在 harness 层，产品差异的 80% 在 harness 层。
> Agent PM 的杠杆 = 设计 harness 的约束（工具暴露、权限、反馈、上下文策略），而非改 prompt 玄学。

**八层要点速记**：

```text
① 是什么   → 模型之外的一切：Agent Loop / Tool System / Context Management /
             Permission / Scaffolding / Environment Interface
② 为什么   → LLM 输出文本 ≠ 行动，缺一整层工程；function calling → 专业 harness 产品化
③ 数学     → MDP 在线执行 + RL rollout 环境（harness 决定训练分布）+ 信息瓶颈设计者
④ 工程     → 主循环 / JSON Schema 工具协议 / 压缩-裁剪-检索 / 授权模型 + hook + 沙箱
⑤ 为什么有效 → 有界灵活性：确定性在 harness 层，灵活性在模型层
⑥ 替代方案 → prompt 驱动（脆弱）/ 专用集成（不可复用）/ 全自主（不可控）/
            轻量库（控制权 vs 生产力）
⑦ 工业界  → Claude Code + Agent SDK（harness 平台化）/ Codex / OpenClaw / MCP 标准化
⑧ 连接     → RL Data（轨迹回流）+ Agent 评测（行为 vs 能力分水岭）+ 产品决策杠杆
```

**面试可用金句**：
- 「同一个模型，换 harness 行为天差地别——这是模型公司亲自做 harness 的原因（第二护城河）」
- 「Agent 评测和模型评测的分水岭：模型评测测能力上限，Agent 评测测行为（工具选择、错误恢复、权限边界）」
- 「改模型能力要重训（慢贵），改 harness 行为是产品迭代（快便宜）」

## 三·五、采集评测设计（同日追加）

**触发点**：复盘优势盘点 → 发现评测链三环节（采集→质检→应用）中采集缺评测。

**产出**：`projects/vlm-multivideo-data-production.md` 新增「十二、Evals 落地 4：采集环节评测」

**核心设计（四指标）**：

```text
M1 覆盖度矩阵：类型×场景×关键词 → 对齐标准拆解，缺格补格
M2 可配对率：  抽样人工标注，L2/L3 样本可构造性的量化
M3 去重有效量：冗余度指标
M4 类型准确率：关键词召回质量
三层 Grader：统计（全量）→ LLM 预筛（抽样/全量）→ 人工校准（30-50 条）
```

**评测链闭环叙事**：

```text
采集（覆盖度评测·批次统计·确定性低）
  ↓
质检（数据质量评测·单条门控·确定性高）
  ↓
应用（Agent 能力评测·维度化任务）

同一套 Evals 方法论贯穿三环节 = 「评测设计者」差异化标签
```
