## 工作汇报

在视觉理解团队做 VLM 视频标注工作（VLM 多视频数据生产项目的执行层）：

```text
工作内容：
├── 向算法交付：视频素材 + query + answer
├── 视频多样：类型 / 场景 / 内容复杂度 / 拍摄条件
├── query 多样：感知 / 行为理解 / 时序 / 因果推理 / 对比…
├── answer 多样：开放描述 / 选择 / 判断 / 数值 / 多解
└── 核心状态：有直觉（多样性 → 训练不同能力）但无法清晰表述
```

**今日认知跃迁**：通过四视角翻译，把直觉系统化为「三层覆盖框架」——

```text
样本 = 素材（输入）× query（任务）× answer（输出）
├── 素材多样性 → 输入分布覆盖 → 泛化（模型见过多少世界）
├── query 多样性 → 任务类型覆盖 → 能力清单（模型会做多少事）
│   └── 与 L1/L2/L3 能力维度体系直接对应
└── answer 多样性 → 输出空间覆盖 → 输出表达（判别 vs 生成）
```

**"站在人的角度看视频"的价值**：人眼 = VLM 能力参照系（Ground Truth 来源），标注 = 把人类视觉认知翻译成模型学习信号。

## 四视角提炼

- **PM 视角**：出题 = 能力反向设计；"这个问题有没有训练价值"就是数据 PM 的产品判断
- **算法视角**：素材单一 → 过拟合训练分布（泛化失败）；每种 query = 一个能力维度的训练信号；answer 形式决定输出头训练信号
- **工程视角**：多样性的量化管理（能力覆盖矩阵：类型 × 场景 × 关键词）已在项目文档 M1 覆盖度矩阵中落地
- **策略视角**：多样性 vs 数量的平衡；如何验证"多样性补齐后模型能力真的涨了"（Ablation）
