## 一、今日主题

**触发点**：使用 AiMe（字节内部 Agent 平台）的观察——一个入口控制多个业务平台。追问：要支撑这样的产品，数据策略是什么？

**核心产出**：`notebook/AI 数据策略：从 AiMe 到 B 端 Agent 平台.md`（v2 已重构）

**关键复盘（v1 → v2）**：初版讲的是流程层（入口怎么打通、评测怎么闭环）——回答"系统怎么跑"；重构后主线是数据策略五问——回答"系统凭什么越来越强"。

**一句话沉淀**：
> 数据策略 = 五问决策链：采什么（能力地图反推数据地图）、从哪采（来源组合随阶段演进）、怎么用（训练/RAG/抽象分流）、怎么验证（评测 = 数据投资的回报度量）、优先级（预算分配）。架构（MCP/Skills/Tools/Harness）只是这套策略的生产系统。

**要点速记**：

```text
视角校准：流程层回答"系统怎么跑"，数据策略层回答"系统凭什么越来越强"
面试表述：「梳理了 AiMe 的架构」→「建立了数据策略决策链，架构只是落地」

五问：
├── 采什么：能力地图 → 数据地图（= VLM 标准文档拆解的 Agent 平台版）
├── 从哪采：四来源（生产轨迹/人工标注/合成/用户纠正）× 真实性/定向性/成本/风险
│    组合随阶段演进：冷启动标注为主 → 增长期轨迹为主 → 成熟期补合成失败
│    ★ 用户纠正数据 = Agent 平台特有的高质量红利（生产环境免费产出偏好对）
├── 怎么用：训练（泛化/慢贵）/ RAG（高频知识/快）/ 抽象（确定性/可审计）
│    分流标准 = 变化频率 × 需求性质 × 迭代成本 × 可控性；路线可迁移
├── 怎么验证：评测 = 数据投资的回报度量（投资前规格/单变量/护栏/在线行为信号）
│    ROI 语言：每类数据的单位能力收益
└── 优先级：能力缺口优先 + 边际收益递减 + 快赢（RAG）慢赢（训练）节奏 + 战略储备

案例演练：AiMe 数据分析"取数口径错误"
→ 归因（区分模型笨 vs 不懂业务）→ 五问逐一决策 → RAG 快赢 + 轨迹攒量后训练慢赢

基础设施重定位：Harness = 数据采集器（可观测性 = 地基）；MCP = 降低来源接入成本
（N×M→N+M）；Skills = 数据编码形态（数据产品）；Tool 定义 = 数据质量第一道 gate
支点：统一入口 = 数据归集位置（谁在入口谁有数据，谁的 Agent 迭代最快）

B 端变形：冷启动手工 Skills、回流是谈判题（授权+脱敏+合规）、
壁垒 = 客户轨迹积累（模型同质化时代唯一非模型壁垒）

角色代入三件事：建数据需求地图 / 建采集与质量方案 / 跑评测闭环做采数决策
```

**面试可用金句**：
- 「流程回答系统怎么跑，数据策略回答系统凭什么越来越强」
- 「数据策略的起点不是有什么数据，而是要什么能力——数据需求是能力需求的镜像」
- 「不是所有数据都要训练：变化快走 RAG，流程固定抽象成 Skills，能力缺口才训练」
- 「用户纠正数据是 Agent 平台特有的红利：生产环境免费产出的偏好对」
- 「评测不是验收环节，是数据投资的回报度量」
- 「统一入口的战略价值不只是使用成本，更是数据归集位置——谁在入口，谁拥有使用轨迹，谁的 Agent 迭代最快」
- 「B 端数据策略的难点从数据量变成数据回流：冷启动靠手工 Skills，壁垒靠客户轨迹积累」
