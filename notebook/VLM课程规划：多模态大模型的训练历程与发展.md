## 三、自动化提效路线图（模块 6 的前置设计）

### 现状瓶颈

```text
人工看视频 → 人想题目 → 人写 answer/reasoning → 质检
└── 人的思考和理解不可规模化 = 产能天花板
```

### 目标态（2026 工业界已走通的路）

```text
① 模型生成
   ├── LLM/VLM 作为数据生成器，人类提供"生成策略"（场景/
   │   技能导向的 QA 合成——VideoKR 的 skill-oriented QA
   │   synthesis）
   └── 人类角色：定义生成策略 + 审核，不再逐条写

② 自动过滤（核心：判分规范可执行化）⭐
   ├── video-dependency 检查：不看视频答得了吗？
   │   （答得了 = 文字泄漏/单帧捷径，废）——VideoKR 三重过滤
   ├── 自洽性检查：多次生成答案是否一致（self-consistency）
   ├── CoT 检查：推理链完整、证据有时间锚点吗
   └── ⭐ 我们的 39-sheet 判分规范 = 这套过滤器的规则库
       （证据边界/容差/排除项全部可程序化）

③ 人工审核边界 case
   └── 只有过滤后的模糊样本需要人——人做最高价值决策

④ 自进化（进阶版）
   ├── Video-Zero：Questioner-Solver 共进化（模型出题、模型
   │   解题、互相检验，时间定位证据锚定）
   └── LongVT RFT：模型自己的 RL 轨迹回炉成训练数据
```

### 我的独特优势（已有资产映射）

```text
├── 判分规范（证据边界/容差/排除项）→ 自动过滤器的判分规则
├── 质检 Gate 思维（5 层门控）→ 过滤流水线的层级设计
├── price-agent M6 经验 → "轨迹→质量评分→人工审核→训练数据"
│   模式已做过一遍（文本场景），搬到 VLM = 换数据模态，
│   管线逻辑同构
└── RL/RFT 认知（2026 前沿）→ 理解"自动生产的数据如何
    进入训练闭环"（SFT 消费 vs RL 消费）
```
