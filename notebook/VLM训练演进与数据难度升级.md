# VLM 训练演进与数据难度升级

> 定位：VLM 数据生产者的"演进史地图"——理解自己做的数据（多视频、复杂 query/answer/CoT）在 VLM 训练范式演进中的位置与价值。
> 触发：VLM 标注组工作的认知升级（从"人的视角看视频"到"数据在模型训练中的角色"）
> 日期：2026-08-23 / 状态：🌿 持续生长

---

## 一、核心结论（30 秒版）

VLM 从 2019 到 2026 经历了四阶段演进：图文对齐 → 统一生成式 → 视频理解起步 → 长视频复杂推理。数据形态同步升级：时长（秒级→20 分钟+）、难度（单事件→证据稀疏→知识密集型）、是否跨视频（无→公开文献空白）。**我们现在做的多视频复杂推理数据，位于能力演进的最顶层，且是 2026 年公开文献的空白点。**

## 二、训练范式演进史

```text
阶段 0：图文对齐（2019-2022）—— CLIP / Flamingo
├── 训练结构：对比学习（CLIP）+ 交叉注意力（Flamingo）
├── 数据：亿级图文对，静态图片
└── 能力：识别 / 检索 / 简单 VQA

阶段 1：统一生成式 VLM（2023）—— LLaVA 架构定型
├── 训练结构：视觉编码器 + 投影层 + LLM
│   两阶段：PT（特征对齐）→ SFT（指令微调）
├── 数据：图像指令数据（合成 + 人工）
└── 能力：看图对话、图文理解

阶段 2：视频理解起步（2023-2024）—— 视频 = 帧序列
├── 训练结构：帧采样 + 时间池化，短上下文
├── 数据：视频字幕、短视频 QA
└── 局限：<10s 片段、单事件、字幕级信号

阶段 3：长视频 + 复杂推理（2024-2026）—— 当前时代
├── 训练结构：三阶段闭环（LongVT 范式）
│   ├── Cold-start SFT：让模型学会基本输出格式
│   ├── Agentic RL（GRPO 风格）：工具调用 + 联合奖励
│   └── RFT（Rejection Fine-Tuning）：用自身 RL 轨迹再训练
├── 架构：原生视频 token、稀疏注意力（VideoNSA 128K token）、
│   百万 token 上下文
├── 数据：证据稀疏（segment-in-a-haystack）、知识密集型
│   （VideoKR：82 学科 6.4 万知识点的领域知识库）、
│   音视频联合（AV-Think 平均 635 词推理链）
└── 能力：时间定位 + 工具调用 + 证据锚定推理
```

## 三、数据形态演进（各维度）

| 维度 | 早期（2022-2023） | 2026 年 | 我们的工作 |
|------|------------------|---------|-----------|
| 视频时长 | 秒级片段 | 20 分钟+（VideoTemp-o3 >20min 超 Gemini-2.5-Pro） | 多视频联合 |
| 片段难度 | 单事件描述 | 证据稀疏（haystack）、高频运动（JumpScore） | 跨视频证据交叉 |
| 是否跨视频 | 无 | 公开文献空白（multi-video reasoning = open gap） | 我们在做 |
| query | 简单 VQA | 知识密集型多轮指令（VideoKR：找"隐含知识"视频） | 复杂场景指令 |
| answer | 单词/短语 | 工具调用轨迹 + 时间戳定位 + 推理链 | 结构化输出 |
| CoT | 无 | 逐时间戳证据锚定（TAVIT） | reasoning 字段 |

## 四、为什么数据必须越来越难（机制）

```text
① 学习信号饱和：简单数据被学会后 loss 收敛，不再提供梯度
   → 只有"能力边界附近"的数据有学习价值（Learnability 最优
   难度窗口：太简单学不到，太难学不会）
   → 高难度数据 = 能力边界处的新信号

② 评测驱动：Benchmark 升级（VideoMME 长视频、JumpScore 高频
   运动）→ 数据难度必须跟上，否则指标上不去

③ 能力分层：识别 → 描述 → 推理 → 证据锚定 → 跨视频联合
   每层需要对应难度的数据——我们在最顶层

④ 反捷径（anti-shortcut）：2026 年数据构造核心方法论
   ├── VideoKR 三重过滤：self-consistency（自洽性）、
   │   video-dependency（不看视频答不了）、CoT
   ├── 目的：消除"文字泄漏/单帧捷径"——模型必须真看视频
   └── 与质检标准同构：判分规范"证据边界"部件 = 保证
       答案证据必须来自视频（与我们的评分标准 5 部件一致）
```

## 五、认知升级（字段级理解）

```text
从"人的视角看视频" → "数据在演进史的位置"：

query 变难 = 教模型处理更复杂的指令空间
answer 变难 = 教模型输出更结构化的结果
reasoning 变难 = 教模型证据锚定式推理（2026 主旋律）
跨视频 = 教模型联合推理（行业空白，先行者）

一句话版本：
"我做的是 VLM 能力演进最顶层的训练数据——跨视频联合推理。
2026 年公开文献里多视频推理数据集还是空白，我在字节内部
做的就是补这个空白的生产管线。"
```

## 六、知识树连接

```text
Multi-modal Data ← → VLM 训练演进：数据难度 = 能力演进顶层信号
Visual Reasoning ← → 证据锚定：六类能力短板（时间交叉引用/实体
    匹配）正是 2026 数据构造的主战场
Video SFT Data ← → 三阶段闭环：SFT 只是第一步，RL/RFT 在
    消费同类数据（我们的数据与 RL 数据的桥梁是 reward 可执行化）
Video Data Pipeline ← → 反捷径过滤：质检的"证据边界"= 数据
    构造的 video-dependency 过滤（模型必须真看视频才能答）
RL Data ← → 联合奖励：answer 正确 + 时间定位（IoU）——未来
    我们数据的消费方式可能是 RL 而非纯 SFT
```
