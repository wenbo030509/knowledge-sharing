# AI Learning System — 个人知识图谱

> 不是成为一个会某项 AI 技术的人，而是成为一个**理解 AI 如何学习（Learning System）的人**。

---

## 这是什么？

这不是一个普通的知识库。这是一套**学习操作系统**。

- 📜 `learning-manifesto.md` — 学习宣言：10 条核心原则，定义了"怎么学"
- 🌳 `knowledge-tree.md` — 知识树：AI Learning System 的完整骨架，持续生长中
- 📅 `daily/` — 每日学习记录：工作汇报 + 对话记录 + 技术解剖 + 知识树生长
- 📁 `projects/` — 项目文档：每个项目独立记录，持续填充
- 📝 `*.md`（根目录）— 专题文章：独立的知识深度文章

---

## 核心原则

> **不以"学了多少知识"为目标，而以"建立了多少连接"为目标。**

每天四个固定动作：

1. **工作汇报** — 今天研究了什么 Pipeline 环节？PM 视角 → 升级工作语言
2. **Technical Anatomy** — 从工作中抽取知识点，带算法视角和工程视角的追问，拆到底
3. **知识树生长** — 把新知识挂到树上，建立新连接
4. **项目文档同步** — 把解剖内容追加到对应的项目文档

## 知识的八层标准

任何知识必须讲够八层才算真正理解，且每一层都要覆盖 PM / 算法 / 工程三个视角：

① 它是什么？ → ② 为什么出现？ → ③ 数学原理 → ④ 工程实现 → ⑤ 为什么有效？ → ⑥ 为什么不用别的方法？ → ⑦ 工业界实践 → ⑧ 与 AI 系统的连接
